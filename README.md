# Jonathan Gelin

**AI harness engineer for developer experience** · Nx Champion · Belgium 🇪🇺

I help engineering organizations adopt AI coding agents at scale: the harness around the agents (skills, plugins, hooks and conventions that teach your standards), the telemetry that shows what works, and the engineering foundations underneath.

[![smartSDLC.dev](https://smartsdlc.dev/linkedin-banner.png)](https://smartsdlc.dev)

## What I work on

- **A harness for coding agents**: plugins and skills that teach Claude Code, Devin, Cursor and others your environment, rules and conventions, tested like code.
- **Measuring agent adoption**: OpenTelemetry and Grafana on the skills used, the cost per successful task and how often a human steps in.
- **Engineering foundations**: polyglot Nx monorepos, conventions and CI/CD that agents can work in.
